# VAULTQUEST – Educational Treasure Hunt Game

## About the Project

VaultQuest is an educational adventure and treasure-hunt game concept designed for students aged 9–14. It combines quizzes, puzzles, exploration, teamwork and stealth challenges to make learning more exciting and interactive.

The game takes players on an adventure through six unique themed rooms. Players explore each room, discover hidden challenges called Locks, solve educational questions and collect clue shards to unlock treasure chests.

## Game Story

Players take the role of a young explorer called the Seeker. With the help of Pip, a friendly robot owl, they explore a mysterious Vault created by Professor Ambrose Quill.

Each room contains five Locks that players must complete before finding the hidden treasure. However, once the treasure map is completed, a ghost called the Husher wakes up. Players must move quietly, hide and avoid being caught while searching for the treasure.

## Six Game Rooms

1. Pirate Cove – Mathematics
2. Haunted Library – Language
3. Jungle Temple – Science
4. Clockwork Lab – Logic and Patterns
5. Frozen Observatory – Geography and General Knowledge
6. The Grand Vault – Mixed Subjects

## Main Features

- Educational quizzes and fun challenges
- Treasure hunting and room exploration
- Friendly ghost stealth challenges
- Hint system with three levels: Nudge, Clue and Reveal
- Rewards including Gold, Battle Points and Gear
- Solo, Squad and Class game modes
- Increasing difficulty across the six rooms
- Child-friendly design and accessibility features

## Target Audience

The primary audience is students aged 9–14. Teachers and parents are secondary audiences who can benefit from the educational and classroom features.

## Project Objective

The objective of VaultQuest is to create a fun and engaging learning experience that encourages curiosity, teamwork, critical thinking and problem-solving.
